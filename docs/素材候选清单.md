# 首批全量素材候选清单（T7 · AI 辅助整理）

> 目标：15~30 张**公有领域**岭南老照片。版权红线：每张必须有明确 license + source_url，
> 宁缺毋滥。优先 1920-1940 广州/珠三角，题材覆盖：骑楼、粤剧、西关大屋、茶楼、
> 珠江航运、庙宇、市集。

## 来源池（按许可友好度排序）

| 来源 | 说明 | 许可状态 |
|---|---|---|
| [Wikimedia Commons: Historical images of Guangzhou](https://commons.wikimedia.org/wiki/Category:Historical_images_of_Guangzhou) | 分类页，含 1920s-40s 街景/珠江/骑楼 | 多为 PD-old 或 CC0，逐张核对 |
| [Wikimedia Commons: Guangzhou in the 20th century](https://commons.wikimedia.org/wiki/Category:Guangzhou_in_the_20th_century) | 按年代细分子分类 | 同上 |
| [Wikimedia Commons: Photographs of Guangzhou by date](https://commons.wikimedia.org/wiki/Category:Photographs_of_Guangzhou_by_date) | 按拍摄日期组织，便于凑年代跨度 | 同上 |
| [Internet Archive: Walks in the city of Canton](https://meta.wikimedia.org/wiki/File:Walksincitycant00graygoog_text.pdf) | 1875 广州城漫步图文书（扫描本） | PD-old；图版可裁切利用 |
| 广东省档案馆开放目录 | [民国教育厅档案目录万余条](https://news.ycwb.com/2023-06/09/content_52001465.htm) | 目录公开≠影像可商用，需逐档确认 |

## 筛选标准（入库硬门槛）
1. 页面带明确许可标记（PD-old / PD-China / CC0 / CC-BY 均可；CC-BY-NC 不要）
2. 分辨率 ≥1200px 长边（SadTalker 与上色都需要细节）
3. 单张人物清晰者优先（口播视频需要正脸或半身）
4. meta.csv 六列补全：photo_id/title/year/location/license/source_url

## 执行步骤
1. 在 Commons 分类页逐张浏览，把候选存入 `data/raw/<photo_id>.jpg`
2. 同步登记 `data/raw/meta.csv`（source_url 用 Commons 文件页而非直链）
3. 满 15 张后跑：`uv run python -m app.cli ingest --src data/raw`
4. 入库报告审查 → 冒烟检索质量抽查
